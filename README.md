# Vamgar (وام‌گر)

**AI Merchant Credit & Working Capital Engine**

Vamgar (از «وام‌گر») یک موتور تصمیم‌گیری اعتباری برای کسب‌وکارهای خرد ایرانی است. هدف این پروژه این است که با استفاده از داده‌های واقعیِ تراکنشی (کارت‌خوان، تسویه PSP، سفارش‌های مارکت‌پلیس) به‌جای صورت مالی رسمی یا وثیقه، به بانک‌ها، PSPها، لندتک‌ها و مارکت‌پلیس‌ها کمک کند تصمیم بگیرند:

- به این مرچنت چقدر اعتبار بدهند (سقف امن اعتبار)
- با چه مدل بازپرداختی (اقساط ثابت در برابر درصدی از فروش روزانه)
- ریسک واقعی cash gap این کسب‌وکار چقدر است

## چرا Vamgar؟

مرچنت‌های خرد فروش و تراکنش دارند، اما داده رسمی (صورت مالی، سابقه اعتباری، وثیقه) کم دارند. این حلقه باعث می‌شود یا رد شوند یا با فرایندهای سنگین (چک، ضامن) مواجه شوند. Vamgar داده‌های پراکنده تراکنشی را به یک تصویر ریسک و ظرفیت بازپرداخت تبدیل می‌کند — قبل از اینکه اعتباردهنده کور تصمیم بگیرد.

## مدل کسب‌وکار

جزئیات کامل ایده، بازار هدف، مدل درآمدی و استراتژی محصول در [`docs/business-model.md`](docs/business-model.md) آمده است.

## ساختار پروژه (اسکلت اولیه)

```
vamgar/
├── docs/
│   └── business-model.md      # سند کامل ایده و مدل کسب‌وکار
├── src/vamgar/
│   ├── main.py                # اسکلت API (FastAPI)
│   ├── schemas.py             # مدل‌های داده ورودی/خروجی
│   └── engine.py              # هسته تصمیم‌گیری اعتباری (placeholder)
├── tests/
│   └── test_engine.py
├── requirements.txt
└── README.md
```

این نسخه فقط **اسکلت اولیه** است: API با یک endpoint سلامت (`/health`) و یک endpoint نمونه برای امتیازدهی اعتباری (`/score`) که فعلاً منطق placeholder دارد. منطق واقعی underwriting (تحلیل cash gap، مدل‌سازی ریسک، پیشنهاد ساختار بازپرداخت) در مراحل بعدی توسعه داده می‌شود.

## اجرای محلی

```bash
pip install -r requirements.txt
uvicorn src.vamgar.main:app --reload
```

## وضعیت
