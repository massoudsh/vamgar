# Vamgar (وام‌گر)

**AI Merchant Credit & Working Capital Engine**

Vamgar (از «وام‌گر») یک موتور تصمیم‌گیری اعتباری برای کسب‌وکارهای خرد ایرانی است. هدف این پروژه این است که با استفاده از داده‌های واقعیِ تراکنشی (کارت‌خوان، تسویه PSP، سفارش‌های مارکت‌پلیس) به‌جای صورت مالی رسمی یا وثیقه، به بانک‌ها، PSPها، لندتک‌ها و مارکت‌پلیس‌ها کمک کند تصمیم بگیرند:

- به این مرچنت چقدر اعتبار بدهند (سقف امن اعتبار)
- با چه مدل بازپرداختی (اقساط ثابت در برابر درصدی از فروش روزانه)
- ریسک واقعی cash gap این کسب‌وکار چقدر است

## چرا Vamgar؟

مرچنت‌های خرد فروش و تراکنش دارند، اما داده رسمی (صورت مالی، سابقه اعتباری، وثیقه) کم دارند. این حلقه باعث می‌شود یا رد شوند یا با فرایندهای سنگین (چک، ضامن) مواجه شوند. Vamgar داده‌های پراکنده تراکنشی را به یک تصویر ریسک و ظرفیت بازپرداخت تبدیل می‌کند — قبل از اینکه اعتباردهنده کور تصمیم بگیرد.

## مدل کسب‌وکار

جزئیات کامل ایده، بازار هدف، مدل درآمدی و استراتژی محصول در [`docs/business-model.md`](docs/business-model.md) آمده است.

```
vamgar/
├── docs/
│   └── business-model.md      # سند کامل ایده و مدل کسب‌وکار

│   ├── main.py                # API (FastAPI)
│   ├── schemas.py             # مدل‌های داده (تراکنش، خلاصه فروش، تحلیل cash gap، تصمیم اعتباری)
│   ├── cashflow.py            # تحلیل جریان نقدی واقعی و تشخیص cash gap از روی تراکنش خام
│   ├── engine.py              # هسته تصمیم‌گیری اعتباری (ریسک، سقف اعتبار، مدل بازپرداخت)
│   └── importers.py           # تبدیل export دوره‌ای CSV منابع خارجی به مدل Transaction
├── tests/
│   ├── test_engine.py
│   ├── test_cashflow.py
│   ├── test_importers.py
│   └── test_api.py
├── requirements.txt
└── README.md
```

### API

| Endpoint | ورودی | خروجی |
|---|---|---|
| `GET /health` | — | وضعیت سرویس |
| `POST /score/transactions` | تراکنش‌های خام مرچنت (کارت‌خوان/PSP/مارکت‌پلیس) | تصمیم اعتباری کامل (پایپ‌لاین واقعی: تحلیل cash gap + خلاصه فروش) |
| `POST /score/csv` | export دوره‌ای CSV یک منبع (ستون تاریخ + مبلغ) + `merchant_id` + `source` | تصمیم اعتباری کامل، بعد از تبدیل CSV به تراکنش خام |
| `POST /cashflow/analyze` | تراکنش‌های خام مرچنت | تحلیل cash gap (دوره‌ها، عمق، فراوانی) برای بازبینی |
| `POST /score` | خلاصه فروش از‌قبل‌تجمیع‌شده | تصمیم اعتباری (بدون تحلیل cash gap، برای فراخوان‌هایی که خودشان داده تجمیع‌شده دارند) |

منطق `cashflow.py` جریان نقدی روزانه واقعی مرچنت را از تراکنش‌های خام می‌سازد، موجودی تجمعی را دنبال می‌کند و هر دوره‌ای که این موجودی منفی می‌شود را به‌عنوان یک cash gap (با عمق و مدت دقیق) ثبت می‌کند. موتور امتیازدهی در `engine.py` این عمق/فراوانی را در محاسبه ریسک، سقف اعتبار پیشنهادی و انتخاب مدل بازپرداخت (ثابت در برابر درصدی از فروش) لحاظ می‌کند.

`importers.py` اولین قدم اتصال به داده واقعی است: export دوره‌ای CSV (فرمت رایج کارت‌خوان/PSP/مارکت‌پلیس) را به مدل `Transaction` تبدیل می‌کند. اتصال زنده به API این منابع (به‌جای export دستی) در فاز بعدی است — نگاه کن به Issueهای باز پروژه.
